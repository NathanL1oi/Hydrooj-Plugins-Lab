# problem-difficulty-label

独立的 HydroOJ 题目难度显示插件，拆自 `frontend-bpjudge` 的难度部分。

## 功能

- 在题目列表、题目详情、训练和课程题目列表中，把 `difficulty` 字段渲染为洛谷风格中文难度。
- 在题目创建、编辑页把难度字段替换为中文下拉框。
- 启动时维护系统设置 `problem.categories` 中的“难度”标签组，保留其它标签分类。

## 难度等级

`0` 到 `8` 分别对应：

`暂无评定`、`入门`、`普及-`、`普及`、`普及+/提高-`、`提高`、`提高+/省选-`、`省选/NOI-`、`NOI/NOI+/CTS`。

插件不会根据标签、通过率或提交情况自动批量改写题目的 `difficulty` 字段。
