# hydrooj-contest-fun-kit

比赛互动增强插件，按域和比赛保存数据，不修改 Hydro 原有比赛排名、评测、报名和提交逻辑。

## 功能

- 赛前目标卡：学生填写目标题数、策略和担心点。
- 比赛任务卡：自动根据提交记录生成小目标完成情况。
- 首杀与高光时刻：根据比赛 AC 记录生成题目首杀和阶段高光。
- 赛后复盘时间线：比赛结束后生成单独比赛复盘页，展示提交时间线、题目攻克、目标完成情况。
- 小组参赛模式：教师可在比赛内配置小组，学生可按设置选择自己的小组。
- 所有功能都在单场比赛内单独开关，默认关闭。
