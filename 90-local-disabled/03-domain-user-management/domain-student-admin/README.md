# hydrooj-domain-student-admin

子域学生账号管理插件，入口在「域管理 -> 学生账号管理」。

## 当前规则

- 姓名名单一行一个学生姓名。
- Hydro 的登录用户名直接使用该姓名，例如 `张三`。
- 不需要填写账号前缀、学号或编号位数。
- UID 仍由 Hydro 自动生成。
- 插件会生成一个内部本地邮箱用于满足 Hydro 用户创建要求，但学生登录不需要使用邮箱。
- 默认密码来自页面的「统一密码」字段，也可以在页面中切换为随机密码。
- 创建后会写入托管记录，子域管理员只能重置本插件托管学生的密码。
- 导入预览会显示即将创建的登录账号；确认导入时会按姓名重新生成账号，避免旧预览数据沿用历史随机账号。

## 快速导入

```text
张三
李四
王五
```

导入后，学生使用名单里的姓名作为登录名。
