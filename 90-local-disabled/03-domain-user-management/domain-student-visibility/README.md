# 域内学生可见性控制

面向子域管理员的域管理插件，用于控制普通学生是否可以查看题库入口、题目尝试/已通过统计、难度和题目标签。

## 功能

- 域管理入口：`/domain/student-visibility`
- 子域管理员可配置：
  - 是否允许学生进入题库列表。
  - 是否向学生显示尝试/已通过统计。
  - 是否向学生显示难度与标签，例如“普及-”“提高+”和分类标签。
- 配置只影响普通学生，不影响域管理员、题目管理员、训练管理员和系统超管。
- 题库入口关闭时服务端直接拦截 `/p`。
- 题目统计、难度和标签会在服务端脱敏，并由前端处理局部刷新页面的兜底隐藏。
- 如果同时安装“插件开关中心”，主域超管也可以统一停用本插件入口与运行逻辑。
