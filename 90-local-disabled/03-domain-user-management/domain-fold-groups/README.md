# HydroOJ Domain Fold Groups

为“我的域”页面增加个人视角的可折叠分组展示。它不会创建真实文件夹，也不会修改域权限、访问入口或课程/比赛等业务数据。

## 用法

安装后访问“我的域”，右上角会出现“域分组”按钮。设置页默认按域逐行填写：

- 一级折叠：例如 `课程开发`
- 二级折叠：例如 `课程分区`、`比赛分区`
- 一级留空：该域自动放到“未分组”

如果想一次补充多个域，也可以使用“批量补充”：

```text
课程开发 / 课程分区: JC01, K2026, Y2025
课程开发 / 比赛分区: bs001, cs001
训练归档 / 入门: RM01, TG01
```

未写入配置的域会自动显示在“未分组”里。

## 安装

```bash
hydrooj addon add /absolute/path/to/domain-fold-groups
```

更新或安装后请重启 Hydro。
