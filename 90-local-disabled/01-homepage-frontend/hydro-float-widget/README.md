# hydro-float-widget

Hydro 域级悬浮公告插件。域管理员可以在域设置中填写 Markdown 公告，并控制是否在全站页面右下角显示一个可展开的浮窗。

## 功能

- 在域设置中注册 `Notice` 字段，用于填写浮窗公告内容。
- 在域设置中注册 `enableShowNotice` 开关，用于控制当前域是否展示浮窗。
- 全站自动加载前端脚本，开启后在页面右下角显示通知入口。
- 默认以圆形按钮收起，点击后展开为公告卡片。
- 展开后支持关闭，关闭后回到右下角按钮。
- 支持响应式布局：桌面端固定右下角，移动端展开时适配屏幕宽度。
- 支持亮色/暗色主题变量。
- 公告内容使用插件内置 Markdown 解析器渲染，支持标题、粗体、斜体、删除线、行内代码、代码块、列表、引用、链接、图片和分割线等常用语法。
- 解析器会过滤 `javascript:`、`data:`、`vbscript:` 等危险链接协议，并对文本和属性做基础转义。

## 配置

安装并重启后，进入域设置：

- `浮窗公告`：填写 Markdown 内容。
- `是否展示浮窗公告`：打开后前端才会渲染浮窗。

示例内容：

```markdown
## 近期安排

- 周五 19:00 进行周赛
- 请提前检查账号和编译环境

[查看题单](/p)
```

## 生效范围

插件使用 `AutoloadPage('global_float_widget')`，因此会在所有加载 Hydro 默认前端资源的页面尝试运行。实际是否显示取决于当前域的 `enableShowNotice` 和 `Notice` 配置。

## 安装

```bash
hydrooj addon add /path/to/hydro-float-widget
```

安装后重启 Hydro，然后到域设置中启用。

## 注意

- 每个页面只会创建一个 `#hydro-addon-widget`，避免重复渲染。
- 前端会在 `vjContentNew` 后重新收起浮窗，适配 Hydro 的局部页面刷新。
- 插件使用自己的轻量 Markdown 解析器，不完全等同于 Hydro 后端 Markdown 渲染器。
- 公告为空时仍会出现入口按钮；如果不希望展示，请关闭 `是否展示浮窗公告`。
