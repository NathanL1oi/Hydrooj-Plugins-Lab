# hydrooj-course-lecture-problem

课程小节讲义题插件，用于把课程小节中的一道或多道题作为“讲义”展示，同时不把它们计入本小节成绩。

## 功能

- 在课程小节编辑页和课程包课时编辑页增加“讲义题”多选框。
- 讲义题关系保存到原生 `content` 字段中的隐藏标记，兼容 `course-atr` 只保存 `title/content/pids/pin` 的逻辑。
- 保存时讲义题会临时参与原生校验，落库前由插件从小节 `pids` 成绩题列表中剥离，因此不计入本小节成绩；编辑界面中讲义不会混入可见题目列表。
- 小节详情页会在题目列表上方单独展示“讲义”区，每道讲义都有独立入口。
- 讲义阅读页使用专用课程页面，不进入普通题目详情页，因此不会显示提交、文件、题目编辑等 OJ 题目功能。
- 讲义题面会渲染成受控路由返回的 PNG 图片，不直接输出可复制的正文 HTML。
- 图片按题面内容哈希缓存到 Hydro Storage，题面变化后会生成新图。
- 课程包复制到课程时，讲义题会跟随题目复制和映射流程；落地到真实课程小节后自动剥离为讲义关系。

## 安装

```powershell
hydrooj addon add .\04-course-learning\course-lecture-problem
```

安装或更新后重启 Hydro。建议安装在 `course-atr` 和 `course-package` 之后。

旧版保存失败的小节需要重新选择一次讲义题并保存，新的隐藏标记才会写入。
