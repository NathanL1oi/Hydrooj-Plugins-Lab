# hydrooj-course-package

HydroOJ 课程包插件。它把可复用课程内容作为独立资源管理，当前层级为：

- 课程包
- 章
- 节

插件刻意避开现有课程和文章插件的命名空间：

- 路由前缀：`/course-package`
- 路由名：`course_package_*`
- 模型名：`global.Hydro.model.coursePackage`
- 文档类型：`10880`、`10881`

## 功能

- 创建、编辑、删除课程包。
- 为课程包维护版本，每个版本用 YAML/JSON 描述章、节。
- 支持像课程插件一样逐层创建章、节。
- 节编辑页使用 Hydro 题目选择自动补全，并提供题库式关键词/标记/难度检索；关键词会同时匹配题号、标题和题目标记，例如输入 `trie` 可检索 `#Trie001. 字典树入门`，支持勾选后批量加入题目。
- 导出课程包版本为 ZIP，包含课程包结构和题目本体。
- 从导出的 ZIP 或旧版 JSON 导入到当前域。
- 复制课程包、章、节到已有 `hydrooj-course` 课程中，也可以在目标子域中新建课程。

## 权限设计

- 域管理员始终可以查看、创建、编辑、导入、复制和导出课程包。
- 角色权限页会新增“课程包”权限组，只提供两个可授权权限：查看课程包、复制课程包。
- 顶部导航中的“课程包”入口只对域管理员或拥有“查看课程包”权限的角色显示。
- 复制按钮和复制路由需要“查看课程包”与“复制课程包”权限；目标子域也需要拥有复制课程包权限或域管理员权限。
- 导出课程包 ZIP 不提供可授权权限，只有域管理员可以使用。

## 树结构示例

```yaml
chapters:
  - title: 输入输出与表达式
    content: 章说明，可写 Markdown。
    lessons:
      - title: A+B Problem
        content: 节说明，可写 Markdown。
        pids: [1000]
      - title: 多组输入
        pids: [1001, 1002]
```

也可以直接粘贴 JSON：

```json
{
  "chapters": [
    {
      "title": "第一章",
      "lessons": [
        { "title": "第一节", "pids": [1000] }
      ]
    }
  ]
}
```

旧版 `stages -> chapters -> lessons` 数据仍可导入或打开，保存后会自动压平为 `chapters -> lessons`。

## 复制到课程的映射

现有 `hydrooj-course` 的结构是“课程 -> 章节 -> 小节”，因此本插件复制时做如下映射：

- 复制整个课程包：选择目标子域和目标课程后，每个“章”生成一个课程章节，节生成章节下的小节。
- 复制章：可以在课程根部新建一个章，也可以把该章下的节追加到已有课程章下面。
- 复制节：必须落到一个课程章下面；如果目标课程没有合适的章，可以先新建课程章再复制该节。

复制功能支持在目标子域中新建课程。复制题目时会调用 Hydro 原生 `ProblemModel.copy` 创建目标子域题目引用，题面和数据沿用当前复制来源域；同时会把来源题目的题解内容复制到目标子域题目下，并将课程小节中的题号改写为目标子域中的题号。若目标子域缺少对应引用题，当前用户需要拥有目标子域的题目创建权限，且来源域需要允许复制到目标域。

课程写入依赖已安装的课程插件提供 `global.Hydro.model.course.add`、`addSection` 和 `addSubSection`。

## 导出与导入

课程包导出为 ZIP，包含：

- `course-package.json`：课程包、版本、章、节结构。
- `problem-*` 目录：所引用题目的 Hydro 标准导入结构，包含题面、测试数据、附加文件和题解文件。

导入课程包时推荐上传 ZIP。插件会先导入 ZIP 内题目，再把课程包中每个节的题号重写为当前子域中的题号。旧版纯 JSON 仍可粘贴导入，但不会自动携带题目本体。
