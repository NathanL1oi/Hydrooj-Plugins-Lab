# problem-batch-pid

Hydro 域管理插件：批量修改题库题目的显示 PID。

## 功能

- 在题库列表右侧“创建题目”区域增加“按顺序改题号”入口；同时保留前端增强脚本，能读取当前勾选题目时会自动带入。
- 不覆盖 Hydro 原生题库列表模板，避免影响“默认排序 / 最新题目”等原有功能。
- 支持直接粘贴当前 PID / docId 列表，按输入顺序维护题号，例如 `C001 Z001 B020 B001`。
- 支持从 Excel 粘贴两列：第一列 PID/docId，第二列题目名；第一列为空时会按题目名精确查找题目。
- 不依赖 Hydro 勾选顺序；页面输入框里的顺序才是重新编号顺序。
- 某一行题目没有找到或整行为空时，会保留这一行生成的新 PID，执行时跳过，后续可以单独补题。
- 只有拥有域管理权限的用户可以看到和执行此操作。
- 可按前缀、起始编号、数字宽度自动生成新 PID，例如 `D01` 到 `D30`。
- 执行前预览映射，并检查重复、非法 PID、目标 PID 占用。
- 执行时使用临时 PID 中转，支持互换和平移。

## 使用示例

在题库列表勾选题目后，点击右侧“按顺序改题号”；如果需要自定义顺序，直接在页面输入框中粘贴：

```text
C001 Z001 B020 B001
```

然后填写：

```text
前缀：D
起始编号：1
数字宽度：2
```

预览结果：

```text
第 1 题 C001 -> D01
第 2 题 Z001 -> D02
第 3 题 B020 -> D03
第 4 题 B001 -> D04
```

也可以从 Excel 粘贴两列：

```text
Z027    妙妙咒语
Z141    Inversion
        分割
Z028    枢纽
```

其中 `分割` 这一行第一列为空，会按题目名 `分割` 精确查找；最终仍按这四行的顺序生成新 PID。

如果某一行查不到题目，或中间留了空行，则这一行的新 PID 仍会显示并保留，后面的题目继续按原行号编号，不会前移。
