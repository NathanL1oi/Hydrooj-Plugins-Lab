# Hydro Problem ZIP Replace

在题目详情页右侧提供“替换本题”工具，也在题库入口提供“批量 ZIP 替换”。上传 Hydro ZIP 后覆盖已有题目的题面、标题、标签、难度、配置、测试数据、附加文件和题解。

插件会保留当前题目的 `docId` 和 `pid`，因此课程、课程包、训练里已经引用的题目 ID 不需要修改。
导入时 `problem.yaml` 的 `difficulty` 字段只由该字段本身决定；`tag` 中的难度标签会规范为新版洛谷文案，但不会反向填充或覆盖 `difficulty`。

## 单题替换

1. 打开需要替换的题目详情页。
2. 在右侧“替换本题”中选择单题 Hydro ZIP。
3. 默认同步替换题解：旧题解会清理，ZIP 中的 `solution/`、`solutions/` 或 `sol/` 会重新导入。
4. 确认后上传替换。

只支持单题 ZIP；如果 ZIP 中包含多个 `problem.yaml`，系统会拒绝替换，避免误操作。

## 批量替换

1. 在题库的新增/工具入口打开“批量 ZIP 替换”。
2. 上传包含多个 Hydro 题目的 ZIP。
3. 系统读取每个 `problem.yaml` 的 `pid`，匹配当前域题库中同 `pid` 的已有题目。
4. 先预览映射，全部无误后再确认执行。

批量模式同样保留已有题目的 `docId` 和 `pid`，只替换题面、数据、题解和其它设置。
