此工具保留目标题目的 docId。课程、课程包、训练中已经引用的数字 ID 不需要改；默认也保留原 PID。

支持单题 ZIP，也支持包含多个 problem.yaml 的批量 ZIP。
左边写当前要保留的题目 ID / PID；右边可写 ZIP 内文件夹、ZIP 内 PID 或题目标题。右边不写时，若 ZIP 题目数与行数一致，会按顺序自动匹配。
题解是追加，不删除旧题解。旧提交记录不会清空，已投入使用的题请谨慎替换。
