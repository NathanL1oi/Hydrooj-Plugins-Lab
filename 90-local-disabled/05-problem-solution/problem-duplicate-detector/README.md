# hydrooj-problem-duplicate-detector

HydroOJ 重复题 / 相似题检测插件。

## 功能

- 在「域管理 -> 重复题检测」中扫描当前域题库。
- 综合比较标题、题面、样例、标签、来源链接和引用题。
- 按相似度展示疑似重复题对。
- 支持把误报题对标记为「忽略」，后续扫描默认不再显示。

## 安装

```bash
hydrooj addon add "C:\Users\kkkw\Desktop\hydro插件总\02 目前已装\01 20251018\01 安装\02 新构\problem-duplicate-detector"
```

安装或更新后重启 Hydro。
